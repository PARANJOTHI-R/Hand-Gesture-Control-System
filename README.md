#Hand-Gesture-Control-System
This project leverages OpenCV and MediaPipe to build a real-time hand gesture recognition system that enables users to control core computer operations using intuitive hand movements. Designed with accessibility and multimodal interaction in mind, the system translates hand gestures into actions such as:

🖱️ Cursor movement

👆 Scroll up/down

🖐️ Left and right click

🔇 Mute/unmute system audio

By tracking hand landmarks and interpreting gesture patterns, the system offers a touchless interface that enhances usability for users with limited mobility or those seeking hands-free control. The implementation is modular, extensible
